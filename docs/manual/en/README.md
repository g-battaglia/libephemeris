A beginner-friendly introduction to astronomical and astrological calculations.
16 sections (a preface and 15 chapters) covering the sky, time, coordinates, ephemerides, planets, the Moon,
astrological houses, fixed stars, eclipses, the sidereal zodiac, minor bodies,
and practical recipes.

> No prior knowledge of astronomy or programming required.
