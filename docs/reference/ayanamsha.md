# Sidereal modes (ayanamsha)

LibEphemeris computes every predefined base mode (`SIDM_*`, IDs 0--46). A
normal predefined mode no longer warns or degrades to `SIDM_J2000`.
`SIDM_USER` (255) remains available for caller-defined epochs and offsets.

## Definition model

Every epoch/formula mode is stored as its **published defining pair** — the
ayanamsha value at the author's defining epoch — and propagated at runtime
with the Vondrak, Capitaine & Wallace (2011) Method-B accumulated precession
on the mean ecliptic of that epoch, exactly like `SIDM_USER`:

```
ayanamsha(t) = defining_value + accumP_B(t; defining_epoch)
```

The pairs live in `libephemeris/ayanamsha_definitions.py`, generated by
`scripts/generate_ayanamsha_definitions.py` from the published statements
cited below. Dynamic star and galactic modes are evaluated from live,
independently sourced catalogue geometry (Hipparcos/Gaia/VLBI) against the
published target longitude; nothing is stored as date-indexed output and no
value derives from any external ephemeris implementation.

## Source status

- **Published** — the defining value or rule was taken from the cited
  author's or institution's publication.
- **Geometry** — the value is recomputed at runtime from a cited star
  catalogue or IAU frame definition.
- **Secondary** — the defining epoch is the one consistently reported for
  this mode in the secondary literature; page-level transcription of the
  primary source is still pending and is tracked here.
- **Convention** — a documented numerical convention of this project,
  disclosed inline (used only where no primary statement is accessible).

Zero-epoch entries use 21 March of the stated year (Julian calendar, 12:00,
treated as TT) unless the primary statement fixes the instant; equinox and
solstice instants use the mean-equinox polynomials of Meeus, *Astronomical
Algorithms*, chapter 27. Both conventions bound the anchor uncertainty below
0.1 arcsecond.

## User-defined mode

```python
import libephemeris as leph

leph.set_sid_mode(leph.SIDM_USER, t0=my_reference_jd, ayan_t0=my_offset_deg)
```

`t0` is used as a TT Julian date and `ayan_t0` is the mean ayanamsha at that
epoch. The offset is propagated with the Vondrak, Capitaine & Wallace (2011)
Method-B construction on the mean ecliptic of `t0` — the same model used by
every predefined epoch mode.

## Mean and true values

`get_ayanamsa()` and `get_ayanamsa_ut()` return a mean ayanamsha.
`get_ayanamsa_ex()` and `get_ayanamsa_ex_ut()` add IAU 2006/2000A nutation
unless `FLG_NONUT` requests the mean value. Planetary, stellar, Horizons,
Skyfield, and LEB calculations all use the same dispatcher.
