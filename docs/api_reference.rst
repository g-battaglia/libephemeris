Native Python exports
=====================

This page uses the installed native extension. Build it only after installing
and selecting the candidate wheel; do not add a source checkout to ``sys.path``.

Function and class docstrings describe their individual inputs, returned
channels, units and errors. Source typing is shipped in ``.pyi`` files.
The API reading guide explains UT1/TT and resource-lifecycle conventions.
