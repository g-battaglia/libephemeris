# LibEphemeris for Beginners

A complete introduction to astronomical and astrological calculations: learn
what the numbers mean, then put them to work in Python.

- **[Italiano — LibEphemeris per principianti](it/README.md)**
- **[English — LibEphemeris for Beginners](en/README.md)**

Each edition includes the original fifteen chapters, a preface and twelve
worked recipes. No astronomy background is needed; basic Python is enough.
For concise technical instructions, use the [documentation](../docs/README.md).
