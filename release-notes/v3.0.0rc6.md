## Headline

> **rc6 is a documentation, provenance-disclosure and packaging polish pass.**
> No public API or numeric behaviour changed.

## What changed

**Data provenance disclosure.** Fictitious-body rows without a public source
(Nibiru, Proserpina, the Selena digits, the Waldemath reconstruction) are
documented as disclosed interoperability values recoverable by black-box
Keplerian fits against reference-API output; rows with a genuine publication
now cite it. All numeric values are unchanged. See the Calibration Data
Disclosure in `NOTICE.md`.

**Accurate claims.** The interpolated-apse methodology is now described
accurately (passage geometry from JPL DE440/DE441; coefficients and residual
table fitted against reference-API output used strictly as a black-box
oracle). The ΔT-model and dependency-licensing wording was corrected: the
default `smh2016` ΔT is obtained from Skyfield (MIT), only `espenak_meeus`
is a native reimplementation; the core carries no strong-copyleft
(GPL/LGPL/AGPL) runtime dependency, with certifi's weak MPL-2.0 excepted and
disclosed.

**Licensing surface.** `libephemeris[all]` is permissive-only — the GPL-3.0
`rebound`/`assist` N-body packages are pulled only by the explicit opt-in
`[nbody]` extra.

## Compatibility & quality

- Public API unchanged; 1:1 reference parity preserved (both test backends
  green at 16,024 tests each).
- `provenance:sweep`, `license:check` and `wheel:audit` gates pass.
