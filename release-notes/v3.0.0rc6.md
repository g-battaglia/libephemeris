# LibEphemeris 3.0.0rc6 — the provenance/independence release candidate

**Release date:** 2026-07-10
**Author:** Giacomo Battaglia
**License:** Apache-2.0
**Python:** >= 3.12
**Status:** Release candidate of the v3.0.0 line, published on the PyPI
pre-release channel; promoted to `3.0.0` final unchanged if it proves clean.

---

## Headline

> **rc6 makes the project's Apache-2.0 independence from the Swiss Ephemeris
> demonstrable, not just asserted.** After an external license audit of rc5, a
> multi-round adversarial remediation re-derived the last reference-influenced
> code as independent expression, put honest provenance on every data set,
> corrected over-broad independence/licensing claims, and hardened the
> provenance gates — then certified the result. No public API or numeric
> behaviour changed.

## What changed

**Code re-derived as independent expression (verified bit-identical).**
The `house_pos` placement branches that had been described in-code as "1:1
ports" (Topocentric/Polich-Page, Horizon, Carter, Krusinski-Pisa-Goelzer,
Savard-A, Sripati, Sunshine/APC) and their helper layer were rewritten from the
published system definitions, delegating coordinate rotation to this project's
own `utils.cotrans`. The global/local lunar-occultation search skeleton was
restructured into documented shared helpers with each parameter given its
physical derivation. Both rewrites were verified **bit-identical** to the
pre-rewrite code (house_pos over a 9,000-sample grid; occultation via the full
test suites), so parity is untouched.

**Honest data provenance.** Fictitious-body rows without a public source
(Nibiru, Proserpina, the Selena digits, the Waldemath reconstruction) are
reclassified as **disclosed interoperability values**, demonstrably recoverable
by black-box Keplerian fits against reference-API output; rows with a genuine
publication now cite it. All numeric values are unchanged.

**Accurate claims.** Categorical "no license obligation" / "contains no derived
code" statements were replaced with the project's working standard and explicit
disclosures. The interpolated-apse methodology is now described accurately
(passage geometry from JPL DE440/DE441; coefficients and residual table fitted
against reference-API output used strictly as a black-box oracle). The ΔT-model
and dependency-licensing wording was corrected: the default `smh2016` ΔT is
obtained from Skyfield (MIT), only `espenak_meeus` is a native reimplementation;
the core carries no strong-copyleft (GPL/LGPL/AGPL) runtime dependency, with
certifi's weak MPL-2.0 excepted and disclosed.

**Licensing surface.** `libephemeris[all]` is permissive-only again — the
GPL-3.0 `rebound`/`assist` N-body packages are pulled only by the explicit
opt-in `[nbody]` extra.

**Enforcement.** The provenance sweep (`scripts/check_provenance.py`) gained an
AGPL class, a tracked-file filename gate against reference-distribution data
files, and a shipped-data license scan; SPDX headers are complete. The full
remediation and the scoped independence certification (zero in-scope defects)
were recorded in a process document since removed from the tree (available in
the repository history); the current summary lives in `NOTICE.md`.

## Compatibility & quality

- Public API unchanged; 1:1 reference parity preserved (both test backends
  green at 16,024 tests each).
- `provenance:sweep`, `license:check` and `wheel:audit` gates pass.
