## Headline: LEB State Management Fixes

LibEphemeris 1.6.0 fixes critical bugs in the LEB fast path introduced
in v1.5.0 that caused crashes when using `lun_occult_when_loc()` and
when reusing the library after `close()` or `set_leb_file()`.

No new features or API changes. Fully backward-compatible.

### Bugs Fixed

**1. `lun_occult_when_loc()` crashed in LEB mode**

The local occultation search defined a shared `_angular_separation_at_jd`
closure that referenced Skyfield-only variables (`ts`, `earth`,
`observer`, `moon_body`). With the LEB fast path active (the default),
these variables were never bound, producing:

```
NameError: cannot access free variable 'ts' where it is not associated
with a value in enclosing scope
```

Fix: added a LEB-native `_angular_separation_at_jd` closure using
`_topo_ecliptic()` and `angular_separation()` (Vincenty formula),
matching the pattern already established in `heliacal.py`. The Skyfield
version was moved inside the `else:` branch.

**2. `close()` left stale `_active_reader` in `fast_calc.py`**

After `close()`, the module-level `_active_reader` still pointed to the
closed LEB reader whose mmap had been released. The next calculation
through `_pipeline_icrs` -> `_frame_data()` would dispatch to
`_get_leb_frame_data(_active_reader, jd_tt)`, crashing with:

```
TypeError: a bytes-like object is required, not 'NoneType'
```

Root cause: `_topo_ecliptic()` and `_apparent_icrs_cartesian()` called
`_pipeline_icrs()` directly, bypassing `_fast_calc_core()` which was the
only code path that updated `_active_reader`.

Fix (belt-and-suspenders):
- `_pipeline_icrs()` now binds `_active_reader` at entry
- `_close_inner()` now calls `_reset_active_reader()`

**3. `set_leb_file()` did not clean up stale state**

Switching LEB files via `set_leb_file()` closed the old reader but did
not reset `_active_reader` or clear `_leb_frame_cache`. Subsequent
calculations could dispatch through the closed reader or serve cached
frame data computed from the previous ephemeris.

Fix: `set_leb_file()` now calls `_reset_active_reader()` and clears
`_leb_frame_cache` after closing the old reader.

**4. `clear_caches()` was incomplete**

`_leb_frame_cache` (Dict keyed by `jd_tt`) and the refraction
atmosphere-profile cache (`_refr_cache_key`, `_refr_cache_func`) were
not cleared by `clear_caches()`. Now included.

**5. `__version__` mismatch**

`__init__.py` declared `"1.4.0"` while `pyproject.toml` declared
`"1.5.0"`. Aligned to the canonical version.
