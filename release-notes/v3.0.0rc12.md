## Hamburg-school companion (IDs 40–47)

The `uranians` group returns as a **companion-only** LEB2 file
(`{tier}_uranians.leb2`), fitted from the independently sourced propagation in
`libephemeris.hypothetical` — never from legacy or third-party coefficients.

- **Generation:** the standalone `ephemeris_{tier}_uranians.leb` partial is
  built via `scripts/generate_leb.py --group uranians` and never merged into a
  main file (mains carry no fictitious body IDs). Angular channels use a
  `1e-12` native-component compression target.
- **Trust:** the companion is attached and consulted only when it byte-matches
  its `DATA_FILES` SHA-256 pin, at both composite discovery and calculation
  sourcing. Legacy or unpinned artifacts are skipped and fall back to the
  runtime model; `fast_calc` continues to reject IDs 40–58 from persisted
  channels.
- **Dispatch:** with a trusted reader active, the Uranian branch sources the
  body and Earth positions from the LEB (same transform and finite-difference
  chain), leaving the public output within the accepted `<0.001"` LEB class and
  identical to the runtime model in Skyfield mode.
- **Bundling:** `base_uranians.leb2` (~46 KB) ships in the wheel; the medium
  and extended companions are hash-pinned downloads.

See `docs/methodology/hypothetical-bodies.md` and `docs/leb/guide.md` §13.

## Definitive `data-v2` data release

Every downloadable asset the library pins — the reviewed regenerated LEB2
cores, the new uranians companions, and the (unchanged) planet-center BSP
subsets — is served from the single definitive **Data Files v2** release, so
nothing depends on the earlier release. The bundled base core stays a package
resource in the wheel and is numerically identical to the data-v2 core.

## Other changes

- Body ID 49 (Nibiru) is documented as fail-closed (no credible published
  numerical orbit); position requests raise `UnknownBodyError`.
- Expanded regression coverage for the companion generation, trust gate,
  file-backed dispatch, packaging manifest, and download pin wiring.
