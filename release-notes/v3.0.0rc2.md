**Release date:** 2026-06-29
**Author:** Giacomo Battaglia
**License:** Apache-2.0

**Status:** Second release candidate of the v3.0.0 line, published on the PyPI

## Headline

> **v3.0.0 is the Apache-2.0, clean-room provenance release that re-grounds the
> whole library on long-term-valid models** — Vondrák 2011 precession &
> obliquity, long-term sidereal-time house cusps, and a multi-era Delta T with a
> selectable model — and ships a full review-driven correctness sweep across
> eclipses, houses, fixed stars, minor bodies, and the LEB / Horizons backends,
> all under a hardened test-and-validation regime — while keeping the v2
> canonical bare-name public API and 1:1 reference parity except for documented
> intentional divergences.

`3.0.0rc2` is the second release candidate of the v3 line and the first to ship
under the new license: it **relicenses the project to the permissive Apache
License 2.0.** There are no functional code changes versus `3.0.0rc1` beyond the
licensing and metadata updates described here. For the complete v3 change recap
(the engineering content), see [`v3.0.0rc1.md`](v3.0.0rc1.md) and `CHANGELOG.md`.

```bash
pip install --pre libephemeris==3.0.0rc2
```

## What changed in 3.0.0rc2 (vs 3.0.0rc1)

### Relicensed to Apache-2.0

LibEphemeris is now licensed under the **Apache License, Version 2.0** — a
permissive license that is free for any use, including closed-source and
commercial products, subject to preservation of copyright, license, and
attribution notices.

This replaces the previous **dual `AGPL-3.0-only OR
LicenseRef-LibEphemeris-Commercial`** model. Concretely:

- The [`LICENSE`](../LICENSE) file now carries the Apache License 2.0 text.
- Every owned source file's SPDX header is `Apache-2.0`; the public
  `libephemeris.__license__` dunder and the PyPI `license` metadata read
  `Apache-2.0`.
- The provenance gate `scripts/check_spdx_headers.py` expects the Apache
  identifier; the three vendored files (`vendor/spktype21.py`,
  `moon_theories/tass17.py`, `moon_theories/tass17_data.py`) keep their
  permissive **MIT** licenses.
- The commercial-licensing scaffolding was removed: `COMMERCIAL-LICENSE.md` is
  deleted, and `LICENSING.md`, `NOTICE.md`, and `THIRD_PARTY_NOTICES.md` were
  rewritten for the single Apache-2.0 grant. The independence / clean-room
  provenance records are retained.

Versions published under the previous AGPL/commercial grants (≤ `3.0.0rc1`)
remain available under those terms; the relicense applies to `3.0.0rc2` onward.
Because PyPI versions are immutable, the Apache build carries a new pre-release
number (`3.0.0rc2`) rather than re-publishing `3.0.0rc1`; the `3.0.0` final
follows once the candidate proves clean.

### Optional `nbody` extra (GPL-3.0)

The opt-in `libephemeris[nbody]` (and `[all]`) extra installs `rebound` and
`assist`, which are **GPL-3.0-or-later**. They are not part of the core install
and are **never bundled** in any LibEphemeris artifact. Because Apache-2.0 is
one-way compatible with the GPL, a user who installs the extra forms a combined
runtime work that is, for that user, governed by the GPLv3. The default/core
library and all of its required runtime dependencies remain fully permissive,
and the shipped wheel contains no copyleft code. See
[`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md).

## Upgrading

Upgrading from `3.0.0rc1` requires no code changes. Upgrading from **v2** carries
the same deliberate behavior changes documented for the v3 line (default sidereal
ayanamsha, eclipse retflags/obscuration, error policy, fixed stars, remote-epoch
positions, house speeds) — re-check any pinned values against
[`v3.0.0rc1.md`](v3.0.0rc1.md),
[`docs/guides/migration-guide.md`](../docs/guides/migration-guide.md), and
[`docs/comparison/intentional-divergences.md`](../docs/comparison/intentional-divergences.md).
