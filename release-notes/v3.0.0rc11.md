## Breaking changes

These affect existing callers; all other behavior matches rc10 to the
sub-arcosecond level.

- **Six hypothetical IDs now fail closed.** IDs 48, 49, 54, 55, 57, and 58
  keep their public names and constants but raise `UnknownBodyError`. No
  source-complete published definition could be recovered for these IDs;
  `docs/methodology/missing-hypothetical-models.md` is the field-by-field
  inventory of what each model would need to be restored.
- **White Moon / Selena (56) follows the published convention.** It now uses
  the uniform seven-year rule from Velichko and Larin (2007), unwrapped from
  the 1800–2000 baseline. Returned positions differ from the legacy convention
  and from any implementation fitted to it.

## Hypothetical bodies (IDs 40–58)

Thirteen IDs compute from primary published sources, transcribed page by page
and documented in `docs/methodology/hypothetical-bodies.md`:

- **Cupido–Poseidon (40–47):** James Neely, "Orbital Elements for the
  Transneptunian Planets," *Matrix Magazine* VII (1980), Table I, p. 10.
- **Harrington (50):** R. S. Harrington, *AJ* 96 (1988), p. 1478.
- **Le Verrier (51):** Le Verrier, *Comptes rendus* 23 (1846), p. 432 and the
  longer *Recherches*.
- **Adams (52):** J. C. Adams (1846), sections 47–48.
- **Lowell (53):** Percival Lowell, *Memoir on a Trans-Neptunian Planet*
  (1915).
- **White Moon / Selena (56):** Velichko and Larin, *Lilith, Selena,
  Proserpina* (Mir Uranii, 2007), pp. 17, 18, 20, 29, 45.

The six remaining IDs (48, 49, 54, 55, 57, 58) fail closed. A recognised name
is not a numerical model.

## House systems

The Savard-A (J), Krusinski (U), APC (Y), and Sunshine–Makransky (i)
constructions are reimplemented from published geometric definitions in
`libephemeris/house_constructions.py`, using vector geometry with an invariant
great-circle branch selection. **Behavior is unchanged:** a 10,992-case
real-date comparison with the reference API (both polar bands, matched ΔT)
reports zero mismatches and a worst cusp deviation below `2e-9` degrees.

## Lunar apsides

The legacy mean-apse compatibility baseline is removed from runtime and
generation. Mean lunar points use ERFA's IERS 2003 Delaunay arguments and
documented orbital-plane geometry; interpolated apogee/perigee use the
separately generated DE440 apsis-passage model. The only observable change is
that `INTP_APOG` and `INTP_PERG` move by at most ~0.031″ as they are anchored
to the actual JPL DE440 passages; mean points, the true node, and the
osculating apogee are unchanged.

## Compatibility summary

- Positions of the Sun–Pluto, Earth, the Moon, the nodes, and the mean/
  osculating apsides are bit-identical to rc10.
- All standard house systems at ordinary latitudes are bit-identical to rc10.
- The four special house systems (J, U, Y, i) are behaviorally identical to
  rc10 by construction.
- The only deltas versus rc10 are: the two breaking hypothetical-body changes
  above, and the `INTP_APOG`/`INTP_PERG` apsis re-anchoring (≤0.031″).
- The Kerykeion consumer suite passes 9,721 / 0 failures against this checkout
  (White Moon report fixtures regenerated locally).
