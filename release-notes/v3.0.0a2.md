## Headline: long-term precession (Vondrák 2011)

LibEphemeris 3.0.0a2 replaces the **IAU 2006 precession polynomial** with the
**long-term precession model of Vondrák, Capitaine & Wallace (2011)**
(A&A 534, A22) across the entire apparent-place reduction.

The IAU 2006 polynomial is only valid a few centuries from J2000 and
extrapolates badly at remote epochs. The published Vondrák model is valid over
±200,000 years. Independent DE441/ERFA validation shows substantially improved
remote-epoch frame behavior.

**Modern results are unchanged** to sub-milliarcsecond (Vondrák ≡ IAU 2006 near
J2000); the JPL/ERFA regression baseline was regenerated.

### Clean-room provenance

The model is obtained entirely from **PyERFA/ERFA (BSD/SOFA)** reference
routines (`ltp`/`ltpb`/`ltpecl`/`ltpequ`/`numat`). No coefficients are
transcribed by hand and no reference-implementation source is consulted;
pyswisseph is used only as an ephemeral black-box validation oracle; its values
are not recorded, fitted, or committed. A new single-source
module `libephemeris/precession_vondrak.py` feeds every reduction path (the LEB
fast path, the Skyfield reference path, and the ecliptic-body / SPK /
fixed-star paths), so the backends cannot diverge at remote epochs.

### Of-date mean obliquity — a documented scientific improvement

The of-date mean obliquity is now taken from the Vondrák poles (the true angle
between the of-date equator and ecliptic poles) **everywhere**, including the
`ECL_NUT` pseudo-body, the galactic-frame sidereal modes, and the node/apside
(`nod_aps`) reduction. This is the physically self-consistent, long-term-valid
obliquity, rigorous where the IAU 2006 obliquity polynomial is an out-of-range
extrapolation.

This is a deliberate use of the independently published Vondrák model at remote
epochs. Differences from other implementations are model-dependent and are
documented without preserving per-date oracle output. See
`docs/methodology/pyerfa-integration.md` for the independent methodology.

## Validation

- Apparent-place reductions are checked against the published ERFA and Vondrák
  conventions across modern and remote epochs.
- LEB values are checked against the independently computed Skyfield/JPL path.
- Public reference-API comparisons are run only as ephemeral compatibility
  observations; their numerical outputs are not stored in release artifacts.
