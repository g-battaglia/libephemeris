# LibEphemeris 3.2.2

**Release date:** 2026-10-05
**Python:** >= 3.12

Default LEB2 downloads now use `data-v4`, the complete 2026-10-05 rebuild of
all three tiers. All twelve download hashes and sizes are updated, and the
wheel bundles the matching base core. Base and medium stored coverage gains
one day at each end; per-body source limits remain authoritative.

The old/new audit covered 40,113 stored states and 4,928 public API calls.
There were no newly introduced calculation errors. The largest sampled
Sun/Moon/planet longitude difference was 0.000492 arcseconds. Base minor-body
channels, notably Gonggong, now agree more closely with the selected JPL
kernels. The existing extended Asbolus model limitation remains documented.

For an existing cache, run:

```bash
libephemeris download leb2-extended
```

Choose `leb2-base` or `leb2-medium` for a smaller inventory. Downloads verify
the new SHA-256 before replacing a file. `data-v3` remains available for older
versions and rollback. The Python API and default precision tier are unchanged.

The repository also includes an interruptible, resumable regeneration runner
with per-body checkpoints, frozen source inputs and bounded-memory merges.
See the LEB quickstart and `docs/leb/data-v4-validation.md` for the build and
validation details.
