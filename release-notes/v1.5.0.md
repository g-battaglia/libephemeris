**Release date:** 2026-05-14

## Headline: LEB Fast Path for Eclipse, Heliacal, and Fixed Stars

LibEphemeris 1.5.0 completes the migration of all high-level astronomical
modules to the LEB (Light Ephemeris Buffer) binary fast path. When a LEB
file is configured, the library no longer loads the Skyfield DE kernel
(up to 3.1 GB for DE441) for eclipse calculations, heliacal events,
fixed star positions, or planetary phenomena.

### Performance

| Operation | Before (Skyfield) | After (LEB) | Speedup |
|-----------|-------------------|-------------|---------|
| Solar eclipse search | 0.36s | 0.014s | **~25x** |
| Fixed star position | ~200μs | ~20μs | **~10x** |
| Besselian elements | ~100ms | ~60μs | **~1600x** |

### Precision

All LEB results match the Skyfield reference within sub-arcsecond
tolerance, validated by 117 regression tests:

| Metric | LEB vs Skyfield |
|--------|----------------|
| Besselian elements (x, y, d, l1, l2, μ) | < 6×10⁻⁸ |
| Eclipse timing (maximum, contacts) | < 0.01 seconds |
| Sunrise/sunset (5 locations) | < 0.001 seconds |
| Fixed stars (116 stars, all flags) | < 0.1 arcseconds |
| Moon topocentric position | < 1 arcsecond |
| Velocity (Sun, Moon, planets) | < 0.002°/day |

### What Changed

**New LEB-native modules:**
- `eclipse.py`: All 32 `get_planets()` call sites ported to LEB with
  Skyfield fallback for out-of-range dates
- `heliacal.py`: `heliacal_ut`, `heliacal_pheno_ut`, `vis_limit_mag`
  with topocentric positions and geocentric Moon phase
- `fixed_stars.py`: `_calc_star_position_leb()` with full ICRS
  astrometric pipeline (proper motion, aberration, deflection, frame
  rotation, radial velocity correction)
- `planets.py`: `_calc_pheno_leb()` with 3D vector phase-angle
  computation for all bodies

**New SEFLG flag support in LEB mode:**
- `SEFLG_XYZ`: Cartesian output for all pipelines (A, B, C)
- `SEFLG_TOPOCTR`: via ERFA `c2t06a` with observer position + velocity
- `SEFLG_RADIANS`: angular to radian conversion (skipped for XYZ)
- `SEFLG_NONUT`: mean ecliptic/obliquity for all pipelines
- `SEFLG_ICRS`: falls back to Skyfield (not yet native)

**New utilities:**
- `angular_separation()`: Vincenty formula, stable at all separations
- `_topocentric_offset()`: ERFA-based observer ICRS position/velocity
- `_topo_ecliptic()`: topocentric ecliptic without global state mutation
- `_apparent_icrs_cartesian()`: for Besselian shadow geometry

**Bug fixes:**
- Pre-existing Skyfield `heliacal_pheno_ut` bug: Moon pheno indices
  were swapped (phase angle vs illuminated fraction)
- `SEFLG_NONUT + SEFLG_SIDEREAL`: now uses mean ayanamsha correctly
- Pipeline B/C NONUT: nutation properly stripped for True Node,
  Osculating Apogee, and interpolated bodies

### Fallback Behavior

All LEB dispatch points catch `KeyError` (missing body) and `ValueError`
(out-of-range date, checked via `"outside range"` message) and fall back
to the Skyfield implementation. Eclipse functions that use `set_topo()`
save and restore the previous topocentric state via `try/finally`.

### Known Limitations

- Eclipse search closures don't fall back mid-loop when LEB range is
  exceeded during iterative search. Only affects custom LEB files shorter
  than the search window. Standard LEB files (base: 1849–2150, medium:
  1550–2650, extended: −13200 to +17191) are unaffected. See issue #19.
- `lun_occult_when_glob()` requires the Skyfield DE kernel for its
  vectorized batch scan, even in LEB mode.
